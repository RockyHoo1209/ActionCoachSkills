# 人本教练框架

## 核心模型：人

人本教练模式继承了中国传统文化精华，把人看成立体而完整的整体。
以"人"字为原型，分为**人的两面**和**人生三端**：

```txt
          Why（因何）
           /|\
          / | \
         /  |  \
   What（用何） How（如何）
    （术）      （道）

   内：心态、素质
   外：知识、技能
```

## 第一部分：人的两面

每个人都有内外两面。内外一体，不离身心，若有偏废，人不完整。

**内**：心态和素质。潜藏于性格中，不易觉察却力量巨大。儒家说的"正心、修身"属于内的范畴。
- 为学日益（学习外部知识，天天进步）
- 为道日损（甩掉旧框框，损失过去，得到未来）

**外**：知识和技能。通过后天学习获得，是外在的表现。
- 知识和技能是"套路"（如 MBA、专业资格）
- 心态和素质是"内功"（内功好，套路发挥威力）

**内外关系**：
- 知识多而心态不正 → "残内而坚外"，容易走偏
- 德为先，能力为基础 → 方向偏了，速度越快，毁灭性越大
- 完整的人必定内外兼修，由里及表，和谐统一

**ActionCoach 用法**：
- 当用户只看重"方法"（What）而忽略心态时 → 引导看到"内"的重要性
- 当用户只谈感受（How）而不行动时 → 引导看到"外"的重要性
- 帮助用户理解"为什么知道了方法却做不到"——因为内功不够

## 第二部分：人生三端（因道术）

人本教练模式将"人"字拆分为三端，每一笔对应人生的一个维度：

| 维度 | 对应 | 含义 | 问题引导 |
|------|------|------|----------|
| **Why（因）** | 人字之首笔 | 人生目标与动机，存在的根本 | "你要去哪里？""为什么会这样？" |
| **How（道）** | 人字之捺笔 | 信念和心态，内心的修炼 | "你以什么样的心态去存在？" |
| **What（术）** | 人字之撇笔 | 方法和工具，行动的手段 | "怎么做？用什么工具？" |

**三者关系**：
- 因 → 道 → 术：从根本到表面，从内到外的递进
- 三者统一于"因"（道法自然）
- 道术相分：道在内术在外；道术相对：道是根本，术是工具；道术相通：道影响去向，术推动去向

**用旅行比喻人生三端**：
- Why：去哪里？为什么去？
- How：旅行中保持什么心态？想收获什么感受？
- What：坐火车还是飞机？准备什么装备？

**ActionCoach 用法**：
- 用户说"我想找个好工作" → 追问Why（什么对你来说是"好"？为什么重要？）
- 用户说"我知道应该做到但做不到" → 检查How（心态和信念有问题）
- 用户只谈理想不谈方法 → 引导What（具体用什么工具和方法？）

## 第三部分：教练之"道"（调适性领导力）

### 技术性问题 vs 调适性问题

哈佛教授海菲兹提出的核心区分：

| 维度 | 技术性问题 | 调适性问题 |
|------|-----------|-----------|
| 问题明确度 | 清楚明确 | 不明确，甚至不知道问题是什么 |
| 解决方法 | 有现成答案 | 没有现成答案，需要共同学习 |
| 角色 | 权威给答案，成员执行 | 领导者引导，成员主动创造 |
| 典型场景 | 按流程操作、有标准答案的工作 | 变革、转型、创新 |

### 教练的核心原理

```
信念 → 心态 → 行动 → 成果
  ↑                        |
  +-------- 反馈循环 ------+
```

信念和心态决定了人生的方向和成果。教练的作用就是在"信念→心态"这一段进行调适。

### 教练 vs 其他角色

| 角色 | 焦点 | 方法 | 给出什么 |
|------|------|------|----------|
| 顾问 | 事 | 分析、建议 | 答案和方案 |
| 心理辅导 | 过去 | 治疗、舒缓 | 纠正行为 |
| 培训师 | 我（我知道的） | 传授 | 知识和技术 |
| 教练 | 你（你身上的） | 启发、挖掘 | 盲点发现和潜能激发 |

**ActionCoach 用法**：
- 用户问"你告诉我怎么做" → 不直接给答案，引导用户自己找到
- 用户遇到新问题 → 区分是技术性（有现成方法）还是调适性（需要自身改变）
- 用户习惯依赖 → 帮助转型为"我要做"而非"要我做"

## 第四部分：九点游戏（突破框框）

九个点组成 3x3 方阵，用四条连续的直线一笔连接。

**核心启示**：
- 不敢想、不去想、不突破以前的经验，的确是不可能的
- 将直线延长到方框之外，答案跃然纸上
- 限制你的不是问题本身，而是你给自己画的框框

**ActionCoach 用法**：
- 当用户说"不可能"时 → 引导看到框框在哪里
- 当用户陷入固有思维时 → 用九点游戏启发突破

## 第五部分：因道术三位一体

将"人"字三笔与因道术对应，形成完整的生命运行系统：

```
人字之首笔——因（Why）——人生的根本动机和方向
人字之捺笔——道（How）——内在的信念和心态修炼
人字之撇笔——术（What）——外在的方法和工具
```

三者统一于"因"：道法自然，人的因是自己的生命根由和状态。
"效法"是方法，是为术。一个完整的人，道术统一，统一于因。

## 整体应用原则

1. **从因出发**：任何教练对话都从探索"Why"开始
2. **内外兼修**：不只看行为（外），更要看心态（内）
3. **道术相生**：信念改变行为，行为反过来强化信念
4. **调适为先**：先解决人的问题，事情自然迎刃而解
5. **教练如镜**：教练不提供答案，只帮助对方看清自己

## 边界与局限

- 框架理论性较强，需要结合实际对话练习
- 部分概念（因道术、调适性领导力）对普通用户可能过于抽象
- 人本教练模式假设所有问题的根源都在"人"，忽略了环境制度等结构性因素
- 框架是理解步骤，不是操作步骤，需结合四步教练技巧使用

## A2: 何时触发

- 用户说"我不知道想要什么" → 从Why（因）入手，探索真我价值
- 用户说"我知道要什么但做不到" → 从How（道）入手，检查信念心态
- 用户说"给我方法就行" → 引导看到内外兼修的重要性
- 用户说"不可能" → 用九点游戏启发突破框框
- 用户遇到变革和挑战 → 区分技术性 vs 调适性问题
