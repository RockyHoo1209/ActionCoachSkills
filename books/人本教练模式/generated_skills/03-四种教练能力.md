# 四种教练能力

## 核心框架

四种教练能力是教练的"内功"，它们不是独立的步骤，而是贯穿四步教练技巧每一步的核心能力：

```txt
        聆听（接收信息）
            ↓
        发问（探索方向）
            ↓
        区分（厘清真相）
            ↓
        回应（照见盲点）
            ↑
    （循环迭代，持续深入）
```

## 四种能力详解

### 1. 聆听

**定义**：不是一般意义上的"听"，而是有方向性地聆听——听出对方说出而一般人忽略的内容，以及对方根本没说但在言语神态中已经表现出来的内容。

**聆听的三个层次**：
- **听事实（内容）**：对方说了什么具体事情
- **听情感（感受）**：对方的情绪状态、语气变化、音量高低
- **听意图（出心）**：对方说这句话的出发点、动机、真正想表达的

**三"R"聆听技巧**：
- **Receive（接收）**：听全部内容，不批判、不选择，用心地听
- **Reflect（反映）**：即时反映真实情况，如"这个你已经说了三遍了"
- **Rephrase（复述）**：确认理解无误，"我扼要地说一遍，你刚才表达的是……"

**教练要点**：
- 东方人表达含蓄，喜欢让人"悟"，聆听要听"弦外之音"
- 言不由衷也是心声——不想讲真话本身就是一种心声
- 听者有意是教练的忌讳：不能带着自己的预设去听
- 不能选择性聆听（只听喜欢的）、批判性聆听（一听就评判）、装听或演绎

**使用场景（ActionCoach 集成）**：
- 早安拆解目标时：听出用户说的"想改简历"背后是"想换行业"还是"想要更高薪水"
- 用户说"太忙了"：听出是推脱借口还是真实的精力耗尽
- 用户沉默时：听出沉默中的情绪信号
- 午间触摸时：从回复语气中听出用户的状态变化

### 2. 发问

**定义**：有方向性地提问，帮助聆听更为集中，反映真相，引导对方自我探索。

**两种发问出发点**：

| 类型 | 出发点 | 效果 | 例句 |
|------|--------|------|------|
| 批判性发问 | 指责和批评，证明"我是对的" | 引起对抗和防御 | "我提醒你多次了，为什么还出错？！" |
| 启发性发问 | 探索和了解，关心如何解决问题 | 打开心扉和思维 | "如果从头再来，你会看到什么不同做法？" |

**两种问题类型**：

- **封闭性问题**：求证事实，回答"是/不是"
  - "你完成了今天的计划吗？"
  - "你觉得这个方法可行吗？"
- **开放性问题**：获取更多观点，打开空间
  - "你觉得接下来可以做什么？"
  - "你看到了哪些可能性？"

**教练要点**：
- 避免"为什么"的指责性质问（"为什么你总是……"）
- 多问"什么"和"怎样"（"你觉得什么阻碍了你？"）
- 发问不预设答案，真正的好奇
- 发问是反馈区分的一种形式

**使用场景（ActionCoach 集成）**：
- 当用户说"不知道怎么做"时 → "你觉得如果知道第一步，那第一步会是什么？"
- 当用户说"做不到"时 → "如果一定要做，你会怎么开始？"
- 当用户目标模糊时 → "完成了的样子是什么样的？"
- 晚间复盘时 → "今天哪件事让你最有成就感？"

### 3. 区分

**定义**：分辨事物之间的异同，帮助对方看到自己混淆的概念和盲点。

**核心区分维度**：

**事实 vs 演绎 vs 真相**
- 事实：客观发生的事情（"第二次迟到"）
- 演绎：基于事实的推测（"经常迟到，信用很差"）
- 真相：背后的全部原因（送医院、取资料）

**目标 vs 成果**
- 目标：想要去往的方向（"提升业绩"）
- 成果：实际得到的结果（"找到了不努力的理由"）

**渴望 vs 障碍**
- 渴望：真正想要的（"达到业绩"）
- 障碍：自己设置的栏杆（"人才和社会资源欠缺"）

**区分的形式**：
- 以发问的形式："这些安排是你想要的，还是孩子想要的？"
- 直接指出事实
- 通过回应体验
- 通过比喻引导

**使用场景（ActionCoach 集成）**：
- 用户说"我想赚钱" → 区分"赚钱"是手段还是目标，真正想要的是什么
- 用户说"太难了" → 区分"事实上的困难"和"演绎中的困难"
- 用户完成了一些事但觉得没成果 → 区分"完成度"和"成果"
- 用户在多个目标间摇摆 → 区分"真正重要的"和"紧急但不重要的"

### 4. 回应

**定义**：教练在聆听、发问、区分后，用自己的体验为对方"照镜子"。回应的是当下的体验，不是对错好坏的评判。

**两种回应出发点**：

| 类型 | 心态 | 效果 | 例句 |
|------|------|------|------|
| 贡献性回应 | 贡献自己的体验，关心对方成长 | 对方收到支持 | "我感受到你现在很犹豫" |
| 批判性回应 | 否定和打击，证明自己正确 | 对方辩护或逃避 | "你很贪心！你别转移话题！" |

**教练要点**：
- 回应的是**体验**，不是评判（"我听到你在推卸责任" vs "你在推卸责任"）
- 回应要**真诚、直接、即时**——当下这一刻的体验
- **不是给建议**（"你应该……"）、不是糖衣炮弹（"你很好，但是……"）
- 对方抗拒时：教练保持镇定，自我审视回应是否出发点正确

**回应后的常见反应**：
- 保护自己、自我解释、竭力辩驳、选择性接收 → 需要继续引导
- 自我检视、接受 → 可以推进到下一步

**使用场景（ActionCoach 集成）**：
- 用户反复说"可是……" → 回应"我听到你有很多'可是'，感受到你在找理由"
- 用户说"我今天什么都没做" → 回应"我感受到你有些沮丧，但真的什么都没做吗？"
- 用户兴奋地分享完成 → 回应"我感受到你的成就感，这个感觉很棒"
- 用户沉默很久 → 回应"我感受到你有些犹豫，愿意说说吗？"

## 四种能力的协同关系

```txt
聆听 → 收集信息，了解现状
   ↓
发问 → 探索方向，深挖根源
   ↓
区分 → 厘清事实，揭示盲点
   ↓
回应 → 照见真相，推动行动
   ↑
（整个过程循环迭代）
```

**关键原则**：
1. **聆听是基础**：没有有效聆听，其他三种能力无从谈起
2. **发问是引擎**：驱动对话向深处探索
3. **区分是核心**：教练的功力体现在区分能力上
4. **回应是催化剂**：恰当的回应能让对方瞬间看到盲点
5. **四种能力不分先后**：在实际对话中交叉使用，灵活切换

## 边界与局限

- 四种能力是"内功"，需要在实际对话中反复练习
- 不能代替四步教练技巧（它们是"术"的层面的工具）
- 四种能力发挥的前提是教练保持"无我"心态
- 不适合用户处于极度情绪化状态（先接住情绪）

## A2: 何时触发

- 用户表达含糊 → 调用发问（厘清）+ 区分（厘清事实和演绎）
- 用户情绪明显 → 调用聆听（听情感）+ 回应（照见体验）
- 用户反复纠结 → 调用区分（区分目标和成果）+ 发问（打开空间）
- 用户找借口 → 调用区分（区分事实和演绎）+ 回应（反馈盲点）
- 用户完成目标 → 调用聆听（听成就感）+ 回应（肯定贡献）

## 执行步骤

1. 识别当前对话中需要哪种能力
2. 运用该能力的核心技巧（1-2 个回应/问题）
3. 观察用户反应，判断效果
4. 根据需要切换到其他能力
5. 将关键信息记入 llm-wiki-skill 知识库
