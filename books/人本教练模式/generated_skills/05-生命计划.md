# 生命计划

## 核心概念

生命计划就是在生命的空间坐标中，找到意义和目标，为人生订立一个清晰的方向。

方向感强的人一定是有愿景的人；不知道自己方向的人，对未来混沌不知。

生命计划是一个结合宏观和微观的系统，包含四个方面：

`	xt
愿景（Visions）—— 我想成为什么样的人？
   ↓
价值（Values） —— 什么对我最重要？为什么我要去那里？
   ↓
目标（Goals）   —— 我下一步要去哪里？
   ↓
成果（Results） —— 我如何知道我走到了？
`

## 四个组成部分详解

### 1. 愿景（Visions）

**定义**：愿景是一幅心灵地图，是从未知走向已知的心路历程，把目前的事实、希望、梦想和机会融合在一起所创造出来的未来。

**关键点**：
- 愿景不是预告未来，而是勾画未来的蓝图，从而在现在采取行动去创造未来
- 愿景像磁场强大的地心引力，无论在地球什么位置，都无法抗拒它的吸引
- 愿景越清晰的人，力量就越大
- 愿景发自内心，开始时可能只是一个想法，一旦获得强烈认可，就不再抽象

**教练引导问题**：
- "如果你没有任何限制，你理想中的生活是什么样子的？"
- "五年后，你希望自己在哪里？在做什么？"
- "什么画面让你一想起来就充满力量？"
- "你内心深处最想成为什么样的人？"

**ActionCoach 用法**：
- 新用户刚加入时 -> 探索愿景（不急于设定具体目标）
- 用户完成一个目标后 -> 回顾愿景，与当前进度连接
- 用户感到迷茫时 -> 回到愿景层面重新定位
- 每周/每月大复盘时 -> 愿景牵引回顾

### 2. 价值（Values）

**定义**：价值是人们行为背后的驱动力，决定人们沿着什么道路走下去的原因。教练关心的是心态和行为受什么样的价值观驱使。

**关键点**：
- 在教练领域，价值永远具有相对意义——同一事物对不同的人价值不同
- 教练只是客观反映联系和结果，不评价对错，把决定权留给对方
- 替代价值（金钱、地位等工具性目标）和真我价值的区分

**教练引导问题**：
- "这件事对你为什么重要？"
- "如果达到这个目标，它会给你带来什么？"
- "你平时做决定时，什么因素对你来说最重要？"
- "这是你自己真正想要的，还是别人期待的？"

**ActionCoach 用法**：
- 用户设定目标时 -> 追问目标背后的价值（追问2-3层触及真我价值）
- 用户在做选择时 -> 帮助厘清核心价值观，而非替代价值
- 用户多目标冲突时 -> 用价值观排序

### 3. 目标（Goals）

**定义**：目标将愿景变成现实的阶段性方向，是人们决定下一步去向的行动依据。目标是生命计划中的一个个靶心，让人们有瞄准的方向。

**关键点**：
- 目标必须与愿景和价值连接，才能产生真正的动力
- 教练不能只明确在事件中对方想做什么，还要知道为什么想做
- 目标是真想要的目标，才有最大的动力去排除各种障碍

**教练引导问题**：
- "为了靠近你的愿景，接下来3个月最重要的一件事是什么？"
- "这个目标是你自己真正想要的，还是你觉得'应该'做的？"
- "如果达成这个目标，它会让你更接近你的愿景吗？"

**ActionCoach 用法**：
- 早安卡 -> 将愿景拆解为每日目标
- 目标设定 -> 用厘清目标技术连接愿景和价值
- 用户目标完成率低 -> 回到价值和愿景层面检查目标是否真想要

### 4. 成果（Results）

**定义**：成果是愿景实现的累积性元素，是目标和行动之间的转换器。成果提供检视目标的尺度，反映行为的有效性。

**关键点**：
- 行动是把目标变为成果的唯一途径
- 不积跬步，无以至千里；成果是愿景实现的累积
- 目标 -> 行动 -> 成果，这是一个完整的链条

**教练引导问题**：
- "你如何知道你已经达成了这个目标？"
- "这个星期的成果是什么？离你的目标近了多少？"
- "你做了哪些行动？这些行动带来了什么成果？"

**ActionCoach 用法**：
- 晚间复盘 -> 量化今日成果
- 周报生成 -> 汇总阶段性成果
- 目标拆解 -> 将大目标拆分成可衡量的小成果
- 段位升级 -> 成果累积到一定程度触发段位提升

## 生命计划的整体应用原则

1. **从愿景出发**：所有目标设定都应源于愿景
2. **价值观驱动**：行动力来自价值观的认同，而非外在压力
3. **以终为始**：从愿景倒推目标，从目标倒推行动
4. **成果导向**：成果是衡量进步的唯一标准
5. **定期回顾**：生命计划不是一次定终身，需要定期审视和调整

## 边界与局限

- 生命计划适合深度教练，不适合日常的简单任务拆解
- 需要用户有一定自察能力，否则难以触及真我价值
- 愿景探索需要安全、开放的对话氛围
- 不是每个人都准备好了面对生命计划的深度问题（需要逐步引导）
- 生命计划因人而异，教练不能预设任何人的愿景和价值

## A2: 何时触发

- 新用户首次深度教练 -> 探索愿景和价值
- 用户完成一个重要里程碑 -> 将成果连接到愿景，强化意义感
- 用户长期停滞 -> 重新审视生命计划的四个方面
- 用户目标频繁变更 -> 检查目标是否与愿景和价值一致
- 季度/年度复检 -> 重新评估生命计划

## 执行步骤

1. 判断是否适合进行生命计划对话（用户处于开放、反思状态）
2. 从愿景开始（1-2个引导问题）
3. 连接价值（追问为什么这个愿景重要）
4. 设定目标（将愿景转化为阶段性目标）
5. 定义成果（明确每个目标的衡量标准）
6. 将信息记入llm-wiki-skill知识库，建立长期追踪框架
