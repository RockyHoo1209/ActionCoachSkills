# 九点领导力

## 核心模型

九种领导力构成一个环形模型，起点是激情，第九点是可能性：

```txt
激情 → 承诺 → 负责任 → 欣赏 → 付出 → 信任 → 共赢 → 感召 → 可能性
  ↑                                                                 |
  +------------------------- 循环升华 ------------------------------+
```

## 九点详解

### 1. 激情

**定义**：激情的来源是真我价值，需要通过自由选择来实现，活出真我是真我价值在行动中的外在表现。

**三个层次**：
- 真我价值（最本真的追求）
- 自由选择（必须通过自由选择实现）
- 活出真我（在行动中体现价值）

**注意**：替代价值（金钱、地位等工具性目标）不是真正的激情来源。

**ActionCoach 用法**：当用户说\"不知道想要什么\"或\"没有动力\"时，用三层结构帮用户探索深层动机。

### 2. 承诺

**定义**：承诺的核心是\"对自己负责\"，不是对别人交代。承诺的对象是自己。

**要点**：
- 承诺不是束缚，是主动的选择
- 承诺的力量来自于\"我知道我为什么要做\"
- 没有承诺就没有行动力

**ActionCoach 用法**：用户在制定每日计划时，帮助用户区分\"我今天要做\"和\"我承诺今天完成\"的区别。

### 3. 负责任

**定义**：负责任的态度是从\"我没办法\"到\"我可以选择\"的转变。负责任不等于承担过错，而是承认自己有选择的权利。

**要点**：
- \"我选择，我负责\"vs\"我被逼的，不是我的错\"
- 受害者心态 vs 负责任心态

**ActionCoach 用法**：当用户说\"太忙了没时间\"时，帮用户看到\"没时间\"是一种选择，而不是被迫的结果。

### 4. 欣赏

**定义**：欣赏是看到自己和他人已有的价值，而不是盯着缺失的。欣赏的前提是接纳。

**要点**：
- 先欣赏自己，才能欣赏他人
- 欣赏不是赞美，是看到价值

**ActionCoach 用法**：在晚间复盘时，引导用户看到\"今天做了什么\"而不是\"今天没做什么\"。

### 5. 付出

**定义**：付出是心甘情愿地给予，不求回报。付出是\"我想给\"而不是\"我应该给\"。

**要点**：
- 付出和索取的区别
- 真正付出的人不在意回报

**ActionCoach 用法**：当用户帮助他人时，认可这种付出的价值，而不只是关注目标进度。

### 6. 信任

**定义**：信任的核心是相信他人的根本动机是好的。信任是选择，不是证据。

**要点**：
- 信任不是盲目的，是选择相信
- 信任创造信任，怀疑创造怀疑

**ActionCoach 用法**：教练以信任的态度面对用户，即使用户连续中断也不质疑其动机。

### 7. 共赢

**定义**：共赢是找到各方都能受益的方案，而不是零和博弈。

**要点**：
- 共赢需要格局
- 短期看可能牺牲，长期看是必然

**ActionCoach 用法**：当用户的目标涉及他人（团队目标、家庭目标）时，引导思考共赢方案。

### 8. 感召

**定义**：感召是用自己的真我价值激发他人，不是号召或宣传。感召是双向激发。

**要点**：
- 感召的本质是\"用生命影响生命\"
- 自己活出来的人自然有感召力

**ActionCoach 用法**：Done 协议中的庆祝环节，用用户自己的故事感召他自己继续前进。

### 9. 可能性

**定义**：可能性是九点领导力的最高点。\"空\"不是没有，而是万有之始。谦虚是空的前提，探询是将空转化为可能性的方法。

**要点**：
- \"我不知道\"是创造可能性的起点
- 保持空的心态（谦虚、不预判）
- 不断追问\"还有什么可能性？\"

**ActionCoach 用法**：当用户说\"做不到\"或\"不可能\"时，打破固有框架，引导看到更多可能性。

## 领导力模型的应用原则

1. **九点是内在修炼，不是外在技能** → 教练先用在自己身上，再引导用户
2. **环形结构意味着可以循环提升** → 每完成一次循环，整体水平提升一层
3. **起点是激情** → 没有激情，后面的都不成立
4. **终点是可能性** → 修炼的目的是创造新的可能

## 边界与局限

- 九点领导力是心态层面，不是具体方法层面
- 不适合需要立即行动的场景（先给行动计划，再用领导力深层修炼）
- 部分概念（如\"空\"）对现代用户可能过于抽象，需用大白话解释

## A2: 何时触发

- 用户动力不足 → 激情（探索真我价值）
- 用户计划做不出来 → 承诺（帮助做出真承诺）
- 用户找借口 → 负责任（看到选择权）
- 用户只聚焦负面 → 欣赏（看到已有一切）
- 用户只关注自己 → 付出/共赢（扩展视角）
- 用户不相信能做到 → 可能性（打破框架）
- 用户完成目标后 → 感召（用自己的故事激励继续前进）

## 执行步骤

1. 识别用户当前状态对应的领导力缺口
2. 用该领导力的核心提问法（1-2 个问题）引导
3. 如果有效，记入知识库作为用户画像
4. 如果无效，不强行，换一个角度
5. 完成目标时，展示用户在对应领导力上的成长
